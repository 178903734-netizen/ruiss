Windows 鼠标跨屏到 Mac

点击“录制”，直接按 Windows 键盘组合。映射规则与跨屏键盘一致，例如 Ctrl+1 会让 Mac 执行 Command+1，Win+1 会执行 Control+1。

后退侧键
前进侧键
中键

默认后退/前进/中键分别执行 Mac Command+1/2/3。侧滑滚轮仍沿用罗技软件产生的桌面切换快捷键。

跨屏文件传输

支持多文件和完整文件夹。可从资源管理器或 Finder 直接拖过屏幕边缘；传完会保存到对端接收目录，并在当前应用自动粘贴。

两台机器都填好本机名字、对方 IP 和屏幕布局并保存。鼠标滑到屏幕边缘即可跨屏，键盘、点击和滚轮会跟随当前显示鼠标的屏幕。
