# 2026-08-07 工作日志

## mac→win 跨屏双鼠标修复

- 问题：mac→win 跨屏后 mac 侧光标没消失，mac/win 两边都有鼠标且都在滑动；win 侧已完美。
- 根因：mac.rs 用 NSCursor hide 隐藏光标——app 级 API，只在光标位于 Ruiss 自己窗口时
  生效；跨屏时光标在任意窗口，hide 失效。"移动补藏 + tick 补藏"调的还是 NSCursor hide，
  治标不治本。win 侧用 SetSystemCursor 内核级替换所以完美——两端隐藏机制不对称。
- 修复：mac.rs 的 hide_cursor/show_cursor 从 NSCursor hide/unhide 换成
  CGDisplayHideCursor/CGDisplayShowCursor（CoreGraphics 系统级，与 win 对称）。
  - 幂等标志 CURSOR_HIDDEN：hide 仅 false→true 调一次、show 仅 true→false 调一次。
  - 删 CURSOR_HIDE_COUNT；enforce_cursor_hidden 改空；tap 两处补藏调用删除；
    删未用 use objc::{sel, sel_impl}。
- 验证：mac.rs 在 Windows 不编译（cfg gate），需胡先生在 Mac 端编译确认。
- 改动文件：src-tauri/src/platform/mac.rs；CHANGELOG 已记录。基线 commit efb87af。

## 双鼠标仍在——二次排查（14:17）

- 症状：CGDisplayHideCursor 版已上 Mac，mac→win 仍双鼠标，两边光标都在动。
- 排查结论：代码链路没问题（TakeControl 必发→hide_cursor 必被调到，win 光标能动证明
  TakeControl 已触发）。真正根因是 **CGDisplayHideCursor 只对前台应用生效**——
  Apple 官方文档原话 "To use these functions, your application must be in the foreground"。
  跨屏瞬间 mac 上焦点在桌面/其他 app，ruiss 在后台 → CGDisplayHideCursor 静默无效，
  返回值被 `let _ =` 吞掉，失败了也看不到。
- 为什么 win→mac 完美：win 的 SetSystemCursor 无前台限制；且 mac 作 Sink 本来就不用藏光标。
- 修复方案（照抄 InputLeap/Synergy 的 OSXScreen::hideCursor）：
  1. 私有 CGS API：`CGSSetConnectionProperty(_CGSDefaultConnection(), _CGSDefaultConnection(),
     "SetsCursorInBackground", true)` —— 允许后台进程控制光标（hide/show 前各调一次）。
  2. CGDisplayHideCursor 后补 `CGAssociateMouseAndMouseCursorPosition(true)`，
     InputLeap 注释 "appears to fix mouse randomly not hiding bug"。
  3. CG 调用返回值打日志，别再吞错误码。
- 私有符号在 CoreGraphics framework 导出，自用工具不上 App Store 无审核风险。
