# 2026-08-08

## mac→win 两 bug：已分析并改码（mac.rs）

基线提交 4e43774。三个改动（均在 src-tauri/src/platform/mac.rs，macos 专用、Windows 无法编译验证，需 Mac 实测）：
1. tap 早退 `pid != 0` → `pid == std::process::id()`：只放行本进程注入事件，WindowServer 合成的惯性滚动落回正常路径（跨屏被吞+转发对端）→ 治双屏同滚。验证：跨屏甩触控板，[MAC-SCROLL-DIAG] 应出现"滚轮被吞"且 mac 不再本地滚。
2. 跨屏（blocked，Source 出屏）期间把 MouseMove 也加入吞集合（转发照走 tx.send）：隐藏光标停住，不再跟物理鼠标滑向 Dock/菜单栏。
3. warp_cursor 在 blocked 期间把隐藏光标停到屏幕中心安全区（避开 Dock/菜单栏热区）；返回时 blocked 已置 false，用原坐标出口边。

注意：改 2 会断 Source 侧"坐标镜像"，主返回路径是 Sink 侧 tick 判定（不依赖镜像），Source 兜底返回触发位置会偏移——Mac 上需回归：mac→win 正常、win→mac 正常返回、Dock 不再被隔空触发、惯性滚动不再双滚。
