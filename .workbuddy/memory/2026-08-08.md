## mac→win 两 bug 根因分析（只分析未改码）

1. **跨屏后触控板双屏同滚**：mac.rs tap 回调 `pid != 0` 防回环早退（8907359 为 Sink 注入滚轮放行所加）放行了一切软件合成事件；macOS 触控板惯性滚动（momentum 段）由 WindowServer 合成、pid 非 0 → 直通不吞不转发 → mac 本地滚。主动滑动段 pid=0 正常吞+转发。修法：`pid != 0` 改 `pid == std::process::id()`。验证：跨屏甩触控板，mac 滚但无 [MAC-SCROLL-DIAG] 日志即实锤。
2. **win 任务栏位置 mac Dock 出现鼠标+悬停动画**：Source 侧"移动放行"设计 + warp 到对侧边缘维持坐标镜像 → mac 隐藏光标与 win 光标 1:1 同步，win 到底部时 mac 隐藏光标落在 Dock 热区；Dock 悬停不检查光标可见性必触发动画，且 Dock/菜单栏区域不受 CGDisplayHideCursor 约束（Synergy/Barrier 同款）。修法：blocked 期间吞 MouseMoved（转发不变），光标停住；注意镜像会断，Source 侧兜底返回触发位置偏移要回归测。win 作 Source 有同款隐患（透明光标扫任务栏触发悬停高亮），可对称改。
