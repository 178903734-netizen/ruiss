## 2026-08-06

### 跨屏双光标问题根因分析
- **现象**：跨屏时 Source 端光标没真正隐藏，和 Sink 端注入的光标形成双光标
- **Windows 根因**：`ShowCursor(FALSE)` 是 per-thread 计数，外部窗口的 `SetCursor` 直接绕过了它。不管多频繁补藏都没用
- **Mac 根因**：`enforce_cursor_hidden` 里调 `NSCursor hide` 跑在非主线程（tap 回调线程 / tokio 异步线程），AppKit 静默忽略了调用

### 修改（0820时）
- **Windows**：`ShowCursor` 计数方案 → `SetSystemCursor` 替换系统光标资源为透明图标（内核级替换，不受 per-thread/per-window 限制）
  - `hide_cursor()`：用 CreateCursor 创建 1x1 全透明光标 → CopyCursor 复制 → SetSystemCursor 替换 OCR_NORMAL/IBEAM/HAND/APPSTARTING
  - `show_cursor()`：用 SPI_SETCURSORS 从注册表重载所有光标恢复
  - `enforce_cursor_hidden()`：改为空实现（SetSystemCursor 是系统级的，无需补藏）
- **Mac**：`enforce_cursor_hidden()` 改用 `performSelectorOnMainThread:withObject:waitUntilDone:` 把 NSCursor hide 投递到主线程
