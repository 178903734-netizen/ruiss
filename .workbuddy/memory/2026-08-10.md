# 2026-08-10 — M3 跨屏剪贴板/文件/拖拽 代码落地

## 做了什么
在已完成的 M0/M1/M2（键鼠跨屏）项目上实现 M3：
- 协议 `core/protocol.rs`：启用 ClipboardText/Image，新增 ClipboardFiles、文件分块流 FileStart/Chunk/End/Cancel、DragOffer。
- `net/tcp.rs`：MAX_FRAME 1MB→16MB（图片够用），文件走 256KB 分块。
- `platform/win.rs` + `mac.rs`：clipboard_read（files>image>text 优先级）、
  clipboard_write_text/image/files、start_clipboard_watcher（Win 用
  AddClipboardFormatListener+隐藏窗口；Mac 用 NSPasteboard changeCount 轮询 800ms）、
  is_left_button_down（拖拽检测）。LOCAL_WRITE 标志防回环。
- `clipboard/mod.rs`：ClipboardSync（本机变化→发对端；对端→写本机）。
- `file_transfer/mod.rs`：FileSender 分块发（uuid 标识），FileReceiver 写盘→入剪贴板+emit file-received。
- `lib.rs`：execute_action 加跨屏拖拽（左键按下带剪贴板跨屏+光标处注入粘贴 Mac Cmd+V/Win Ctrl+V）；
  run_incoming_router 分发剪贴板/文件/拖拽；apply_link_config 按 clipboard_enabled 启剪贴板同步；
  注册 send_file / pick_and_send_file 命令；inject_paste。
- 依赖：png / dirs / uuid / tauri-plugin-dialog（Cargo.toml）；capabilities 加 dialog:default。
- GUI：`gui/index.html`+`main.js`+`styles.css` 加"跨屏文件传输"区（选文件发送 + 传输记录 + 监听 file-received）。
- 文档：CHANGELOG 加 M3 条目；PROJECT.md 解锁"文件拖拽"、更新进度。
